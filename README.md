# Neural Core — Interactive 3D WebGL Portfolio

An interactive 3D WebGL portfolio experience built with React, TypeScript, Tailwind CSS, and Three.js, featuring a dark graphite (`#121417`) and pure electric cyan (`#00FFFF`) aesthetic.

## Current Progress

- **Phase 1 — 3D Neural Core**: 210 glowing pure cyan nodes forming a cortical neural network with dynamic proximity synapses, cursor parallax, 3D node repulsion, and damped `OrbitControls`.
- **Phase 2 — Multi-Chamber Scroll Flight**: Scroll-driven vertical camera journey across 5 distinct 3D chambers (`Neural Core`, `Crystal Monolith`, `Protocol Vault`, `Consensus Gate` portal fly-through, and the `Blockchain Stage` with 1,200 morphing particles).

## Local Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
